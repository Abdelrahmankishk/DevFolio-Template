# DevFolio Website Template — Bootstrap 5.3.5

A personal portfolio website template built using **HTML5, CSS3, and Bootstrap 5**. The project features a complete single-page layout with profile information, services, portfolio projects, testimonials, blog posts, and contact details. It also uses the **Typed.js** library to create an animated typing effect in the hero section.

## 📌 Project Overview

DevFolio is a personal portfolio website designed to showcase a developer's profile, skills, professional services, completed projects, client testimonials, and contact information in a modern, organized layout.

The implementation recreates the original DevFolio design using HTML, CSS, and Bootstrap for page structure, styling, responsive layouts, and interactive components. Typed.js is integrated to add an animated typing effect that displays different professional roles in the hero section.

## ✨ Key Features

- **Responsive Navigation Bar:** Fixed navigation with section-based links, collapsible mobile menu, and multi-level dropdown menus.
- **Hero Section:** Full-screen background image, dark overlay, centered introduction, and animated typing effect.
- **About Me Section:** Profile information, personal image, skills, and percentage-based progress bars.
- **Services Section:** Six service cards featuring icons and hover effects.
- **Experience Statistics:** A dedicated section displaying completed projects, years of experience, clients, and awards.
- **Portfolio Gallery:** Six project cards with image zoom effects and project information.
- **Testimonials Carousel:** Bootstrap-powered carousel displaying client testimonials and profile images.
- **Blog Section:** Blog cards featuring images, categories, article descriptions, and author information.
- **Contact Section:** Contact form layout, contact information, location details, and social media icons.
- **Footer:** Copyright information and design credits.

## 💡 Technical Highlights

This project demonstrates practical use of front-end development techniques:

- Structuring a complete multi-section website using HTML5.
- Separating page structure and custom styling using external files.
- Using Bootstrap's responsive grid system to organize page layouts.
- Implementing a responsive navigation bar with collapsible menus and nested dropdowns.
- Integrating Bootstrap components, including the carousel.
- Using Typed.js to create dynamic typing and deleting animations.
- Creating reusable CSS styling with custom properties (CSS variables).
- Applying pseudo-elements (`::before`) for decorative elements and navigation indicators.
- Implementing hover effects and image zoom animations using CSS transitions and transforms.
- Working with background images, overlays, positioning, spacing, and typography.
- Integrating Font Awesome icons into different website sections.
